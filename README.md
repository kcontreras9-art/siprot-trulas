# SIPROT - Inteligencia Artificial

Prototipo experimental para analizar pedidos de TRULAS S.A.S. y estimar el riesgo de retraso.

La aplicación entrena el modelo Gradient Boosting con los 100 registros incluidos en el archivo Excel.
Los resultados son experimentales y no deben utilizarse como única base para decisiones reales de producción.
